Captura do Usage (SSE)

O daemon parseia o stream SSE e extrai o usage do último chunk.

sequenceDiagram
    participant D as 🤖 Daemon
    participant OC as ⚡ OpenClaw API
    participant R as 📡 Registry

    D->>OC: POST /v1/chat/completions
{ stream: true, messages: [...] }
    
    loop SSE Stream
        OC-->>D: data: { choices: [{ delta: { content } }] }
    end
    
    OC-->>D: data: { usage: { prompt_tokens, completion_tokens, total_tokens } }
    OC-->>D: data: [DONE]
    
    Note over D: Parseia usage do último chunk
Calcula estimatedCost

    D->>R: POST /api/tasks/:id/usage
{ inputTokens, outputTokens,
cacheRead, model, durationMs }
    R-->>D: 201 Created

    Note over R: INSERT task_token_usage
UPDATE agent_token_stats (atomic)

Etapas do Pipeline

📥 1. Captura

Agent Daemon

POST /v1/chat/completions com stream: true. Último chunk SSE contém usage com prompt_tokens, completion_tokens, total_tokens.

📤 2. Report

Daemon → Registry

POST /api/tasks/:id/usage com breakdown: inputTokens, outputTokens, cacheRead, cacheWrite, model, durationMs, estimatedCost.

🔄 3. Agregação

Registry

INSERT em task_token_usage + UPDATE atômico em agent_token_stats. Totais por agente, por modelo, por dia. Cleanup: >30d → daily buckets.

📊 4. Visualização

Dashboard

KPIs (total tokens, custo, cache hit rate). Barras empilhadas (input/output/cache por dia). Tabela por agente. Breakdown por task.
